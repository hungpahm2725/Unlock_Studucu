# Studocu Tool - Hướng dẫn cài đặt & sử dụng

> Làm theo từng bước hướng dẫn nha

---

## Tool làm được gì?

| Nút | Chức năng |
|-----|-----------|
| **Tạo file PDF** | Tải toàn bộ tài liệu Studocu thành file PDF |
| **Bypass khóa & mờ** | Phá khóa tài liệu bị làm mờ, vượt giới hạn lượt xem |

---

## Cách cài vào Chrome

### Bước 1: Mở trang Extension

Copy dòng này paste vào thanh địa chỉ Chrome, Enter:

```
chrome://extensions/
```

### Bước 2: Bật Developer Mode

Nhìn **góc phải trên** → bật công tắc **"Developer mode"** (Chế độ nhà phát triển)

### Bước 3: Load tool

- Bấm nút **"Load unpacked"** (Tải tiện ích đã giải nén)
- Chọn thư mục `Tool xóa khóa`
- Bấm **Select Folder**

> Xong! Extension đã có trong Chrome!

---

## Cách dùng

### Phá khóa tài liệu bị mờ

1. Vào tài liệu Studocu bị khóa
2. Bấm icon extension trên thanh toolbar
3. Bấm nút **"Bypass khóa & mờ"**
4. Đợi 1 giây → trang reload → mở khóa!

### Tải tài liệu thành PDF

1. Vào tài liệu Studocu
2. **Cuộn hết từ trên xuống dưới** để load đủ trang
3. Bấm icon extension → **"Tạo file PDF"**
4. OK → Cửa sổ in hiện ra → **Save as PDF**

---

## Lỗi thường gặp

| Lỗi | Cách sửa |
|------|----------|
| Bypass không reload | Bấm lại lần nữa hoặc tự F5 |
| Báo "Không tìm thấy trang" | Cuộn hết tài liệu trước khi bấm PDF |
| Tool không hoạt động | Vào `chrome://extensions/` → Reload extension |
| Bị Cloudflare chặn | Đợi 1-2 phút rồi thử lại |
